# Benchmarking harness

Execute directly. Do NOT delegate to heavy_think. Binding contract: VERIFYING.md.
NOTE: this item is executed by zai/glm-5.3 (orchestrator passes the model override at invoke).

## Purpose

Quantify what the three nozzles save, on real data, before anyone trusts them. Offline replay
over the on-box session corpus; no Pi required at runtime.

## Frozen design

- Corpus: Pi session JSONL files (sampled across projects; `eval/golden-sessions.json` is the
  labeled 12-session subset; the harness must also accept arbitrary session paths).
- TypeScript, node:test, zero runtime deps. Replaces the throwaway Python probes (eval/*.py are
  provenance reference, delete when parity is demonstrated).
- Counterfactual accounting per session: replay messages; simulate (a) baseline: everything
  accumulates; (b) routed: only skills/tools the policy would have loaded count as injected;
  (c) pruned: tool outputs the policy would have pruned are removed at epoch boundaries.
  Token counting: use a real tokenizer or a documented bytes→tokens estimator with the
  calibration constant from baseline-results.json (~3.5 B/t for conversation); state which.
- Jev calls in the harness go through the same injectable client as the extension; `--live`
  flag opts into network (default: fixtures/recorded scores). Recorded-score cache keyed by
  content hash makes replays deterministic and free.
- Output: per-session and aggregate report (JSON + markdown): tokens baseline vs governed,
  % reduction, Jev spend in tokens/USD, latency added per epoch, false-load and false-prune
  rates against eval/expected.json labels.
- Ratchet wiring (M2): `eval/run.ts --check` exits nonzero if golden-set floors regress
  (relevant-skill floors and FP ceiling recorded in eval/expected.json); wire into `npm run check`.

## Milestones

- M1: session parser, replay simulator, accounting, report writer, fixture-mode determinism
  (two runs → byte-identical reports).
- M2: --check gate in `npm run check`, thresholds from eval/expected.json, docs in eval/README.md.

## Acceptance

`npm run check && npm test` green; harness runs fixture-mode with no network; markdown report
committed at eval/REPORT.md; Python probes deleted after parity demonstration.
