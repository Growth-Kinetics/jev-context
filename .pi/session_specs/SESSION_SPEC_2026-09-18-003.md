# Nozzle 3: Epoch pruning

Execute directly. Do NOT delegate to heavy_think. Binding contract: VERIFYING.md.
Owner's ruling: NO deterministic helpfulness checks shipped. All helpfulness judgment is Jev's.
Code owns mechanics only: pair surgery, verdict cache, budget caps, frozen-set application.

## Frozen design

- Trigger: `agent_settled` closes an epoch. Judge the CLOSED epoch's tool call/result pairs
  (hindsight: outcome visible). Never judge mid-loop.
- Judgment: one batched Jev request per epoch. State = the epoch (user message, assistant text,
  thinking, tool call names/args, and the outputs under judgment). Question per pair: Noul
  "Given how this turn concluded, is this tool output helpful to subsequent turns?"
  criteria true = carries information later turns need; false = dead weight.
- Oversized outputs: a single output too large for the state budget is judged on head+tail
  excerpt with prune-bias. This is input preparation, not a helpfulness rule.
- Prune semantics: prune = remove the tool call/result PAIR (provider tool_use/tool_result
  pairing invariant) from the `context`-event message copy. All thinking and text parts of
  those messages REMAIN. Learning stays, garbage goes.
- Threshold: prune at ≥ 0.8 confidence of "not helpful" (i.e. helpful-score ≤ 0.2). Middle band
  keeps. Asymmetric: wrong-keep costs tokens, wrong-prune costs recovery.
- Verdict cache: message id → verdict, judged once ever. Applied sets are byte-stable within
  an epoch; new prunes apply only at the next boundary.
- Transcript immutability: the on-disk session file is NEVER written. Test: hash session file
  before/after a prune application, assert identical.
- Telemetry: `PRUNE_EPOCH: epoch=… judged=… pruned=… kept=… tokens_reclaimed=… scores={…}`.

## Learnings

- Verdict cache key: the pair's toolCall id is the only message id present in both the
  session entries and the context-event message copy (AgentMessage carries no entry id) —
  "verdicts cached by message id" resolved to that key. M2 pair surgery joins on the same id.
- Wiring: `onAgentSettled(event, ctx)` now returns the judge promise (never rejects; internal
  catch → ROUTE_DEGRADED reason=internal). Pi may fire-and-forget; M2 must await
  `pruner.pending()` at the boundary before snapshotting the frozen applied set.
- State budget mechanics (input preparation, not judgment): fixed conversation lines first,
  outputs share the remainder equally, floor 1024B per output, front-clip backstop keeps
  state ≤ cap. Excerpt marker digit-width is upper-bounded so the marker never overflows.
- Fail-static: a failed judgment caches nothing and the pairs stay retry-eligible at the
  next settle (double-settle re-entrancy guarded by an in-flight set). ROUTE_DEGRADED
  nozzle=prune + notify once per error class.
- PRUNE_JUDGED is the judge-time telemetry record. PRUNE_EPOCH (with pruned/kept/
  tokens_reclaimed) belongs to M2 — tokens_reclaimed only exists at application time.
- New config: `pruneThreshold` (default 0.2), `pruneStateCapBytes` (default 60_000).
- Biome formatter rewrapped two long template-literal log lines; fixed by the author with
  `biome check --write` (the gate stays no-write).

### M2

- Applied-set semantics: `refreshAppliedSet()` runs inside the existing `before_agent_start`
  Promise.all (awaits `pending()` first), freezes new verdicts into `applied`, precomputes
  `appliedPruneIds` (score <= pruneThreshold), and emits PRUNE_EPOCH only when the set grows —
  quiet boundaries stay quiet.
- `applyPruneSet` returns the input reference on no-op, so the wiring can tell "no surgery"
  apart from "surgery" and keep Pi's no-op context path (`{}`) intact. An assistant message
  that carried only pruned calls is dropped (no empty husks — provider content must be
  non-empty; mechanics, not judgment).
- Context composition: skill injection owns position 0 via the skill router; prune surgery
  runs on `event.messages` first, then the router receives the (possibly new) event. When
  injection is absent the router's `{}` must not drop the surgery — the wiring patches
  `{ messages: pruned }` in that case.
- `PruneVerdict` gained `outputBytes` for tokens_reclaimed (4 bytes/token estimate over
  pruned outputs; telemetry only, never a decision input).
- Transcript-immutability test hashes a fixture session.jsonl with sha256 across a full
  settle → boundary → pruned-context sequence; the extension never touches the file.
